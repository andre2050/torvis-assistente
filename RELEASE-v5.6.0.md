# Release 5.6.0 — HUB Realista

Versão cumulativa sobre a 5.5.0.

## Destaques

- HUBs geométricos redesenhados com mais profundidade, brilho, vidro e movimento.
- Novo módulo `gui/hubs_realistic.py` desacoplado do canvas principal.
- Reatividade ao áudio, fala, escuta, processamento e modo mudo.
- Reator 3-D preservado e integrado à mesma linguagem visual.
- Fallback gráfico anterior preservado para robustez.
- Nenhuma dependência gráfica nova.

## HUBs preservados

Reator, Hexágono, Prisma, Cubo, Íris, Engrenagem, Átomo, Mandala, Espectro e Vórtice.
