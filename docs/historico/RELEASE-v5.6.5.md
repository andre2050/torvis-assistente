# T.O.R.V.I.S 2026 v5.6.5 — Cowork Resiliente

Correção focada no Cowork/Code Agent que podia aparentar congelamento ou parar no meio de um projeto.

## Correções

- Heartbeat de progresso publicado a cada poucos segundos.
- Guard de tempo para chamadas do modelo de programação.
- Fallback automático do bundle rápido para geração por arquivo.
- Retry de falhas transitórias por arquivo.
- Timeout menor para instalação de dependências no perfil rápido.
- Estado visual ATIVO/AGUARDANDO no painel Code Agent.
- Erros continuam sendo reportados como resultado do trabalho, em vez de sumir silenciosamente.
