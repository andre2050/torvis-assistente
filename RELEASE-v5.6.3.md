# T.O.R.V.I.S 2026 v5.6.3 — Refinamento da Interface e Cowork Rápido

## Interface
- HUB/núcleo central maior e mais responsivo à voz.
- Conversa em blocos visuais separados para VOCÊ e T.O.R.V.I.S.
- Code Agent recolhível/expansível.
- Sete controles inferiores com textos mais limpos e estados consistentes.
- Computer Use bloqueado usa estado de atenção, não erro.
- Sempre Ouvindo mostra ON/OFF visual.
- GPU/temperatura indisponíveis deixam de ocupar a interface com `N/A`.
- Tarefas ociosas viram um cartão compacto.
- Campo de comando maior, com indicação de Enter/ESC.
- Ajustes responsivos para telas menores.

## Cowork Rápido
- Uma única pergunta para começar um novo projeto.
- Classificação local para app desktop, site, API e automação.
- Planejamento rápido sem rodada extra de IA em projetos comuns.
- Geração em lote de pequenos projetos em uma única chamada quando possível.
- Fallback automático para geração arquivo a arquivo se o lote vier incompleto.
- Execução de teste mais curta no modo rápido para não esperar 30 s em servidores/GUI.
- Correção do contador de arquivos ao carregar pastas.
